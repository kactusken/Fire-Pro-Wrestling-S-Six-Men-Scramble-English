# Changelog

## v0.1 (first public beta)
- Complete English translation: menus and modes, the 160-wrestler roster in two patches (real
  names / parody names), move names, Wrestler Edit, Victory Road with all pre-match interviews, the
  endings, Title Match mode, messages and save titles.
- Two-letter characters (184 letter pairs drawn as one sprite) so English fits the game's
  per-line sprite limit; the endings' fixed-width lettering made proportional.
- English pictures: Wrestler Select labels and the five result banners (TITLE WON!, TITLE
  DEFENDED!, CONQUERED!, CHAMPION!, VICTORY!).
- "(Unlocked)" patches, English and Japanese: everything a full game clear unlocks (all 24 hidden
  wrestlers, the full Music Test, edit points) from the start, 255 edit points, nine hidden
  Wrestler Edit presets and the secret G Gundam theme in Wrestler Edit.
